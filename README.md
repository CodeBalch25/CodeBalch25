## Selected personal projects

These public projects are separate from my professional work. Their descriptions reflect the source code, not verified commercial deployment or measured business results.

### [Product Trend AI](https://github.com/CodeBalch25/Product-Trend-AI)

Product research can become disconnected searches and notes. This Python application combines trend discovery, specialist LLM analysis and a human review queue, bringing research and approval into one workflow.

FastAPI, Celery, Redis, PostgreSQL and Docker. Marketplace publishing currently includes demonstration placeholders; the monitoring and repair workflow is experimental.

### [Financial Growth Tracker](https://github.com/CodeBalch25/financial-app)

Income, bills, assets and spending are easier to understand in one view. This budgeting and net-worth application combines account tracking with scheduled LLM summaries that highlight changes and possible next steps.

React, Express, SQLite and Groq, with scheduled analysis and saved insight history.
